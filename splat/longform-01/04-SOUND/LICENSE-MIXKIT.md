- Дата проверки: **16.10.2026**
- Страница лицензий: https://mixkit.co/license/#sfxFree (текст «Sound Effects Free License» подгружается в модальное окно с https://mixkit.co/license/modal/sfxFree/)
- Общие условия (User Terms): https://mixkit.co/terms/ (лицензия действует «с оговорками из User Terms»)

## Что разрешено
- Использовать бесплатно в **коммерческих и некоммерческих** проектах.
- В списке прямо названы: **YouTube-видео**, соцсети, онлайн-реклама, образовательные цели, музыкальные клипы, фильмы, видеоигры, ТВ и радио, CD/DVD.
- Можно скачивать, копировать, **изменять** (обрезка, нормализация, склейка), распространять и публично исполнять звуки как часть конечного продукта (End Product) на любой веб/соцплатформе, в подкастах, играх, фильмах, презентациях, VOD.
- Условие: конечный продукт должен быть **больше по объёму и иным по характеру**, чем сам звук (то есть ролик, а не звук как таковой). 16-минутный документальный ролик под это подходит.
- Монетизация YouTube-ролика допустима («commercial projects», «YouTube videos»).

## Атрибуция
- В тексте лицензии **требование указывать авторство/ссылку не упомянуто** - обязательной атрибуции нет. Ссылка на Mixkit в описании - по желанию.

## Что запрещено
- Распространять звук **отдельно**, как сток, **в составе инструмента/шаблона** или вместе с исходными файлами. Практически: этот пакет SFX нельзя выкладывать публично, раздавать другим авторам или продавать как набор - только использовать внутри своего ролика.
- Выдавать звуки за свои и **регистрировать их в сервисах управления правами** (в том числе вносить в Content ID как свои). Сам ролик со звуками - ок, но регистрировать звуки отдельно нельзя.
- Из User Terms: нарушать Acceptable Use Policy, удалять водяные знаки/копирайт-метки (включая превью-файлы), массово скачивать каталог ботами/скриптами. При нарушении Mixkit вправе прекратить права на использование.

## Как собран пакет
- Файлы выбраны по страницам категорий mixkit.co, использованы официальные WAV-файлы бесплатной загрузки (`https://assets.mixkit.co/active_storage/sfx/<id>/<id>.wav`), превью-mp3 нужны были только для подбора. Для каждого файла в `SFX-MANIFEST.tsv` указаны название на Mixkit, страница, URL превью и примечание о правках.
- Это краткий пересказ, а не юридическая консультация: перед публикацией сверьтесь с актуальным текстом по ссылкам выше. Файл `sfx16-mouse-clicks.wav` - производная сборка из кликов Mixkit, к нему применяются те же условия.

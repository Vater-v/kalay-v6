# Графика: стиль, файлы, как перерендерить

## Стиль «ночной стол»

- **Минимализм:** каждый объект в кадре что-то сообщает; декора нет. Один крупный смысловой акцент на кадр.
- **Фон:** тёмное зелёное сукно с медленно плывущим мягким светом (`G00-bg.mp4`, 10 с; зерно выключено — включается параметром `grain=1`). Под все скриншоты постов — он, а не чёрный. Если нужно дольше 10 с — поставить подряд с перекрёстным растворением 0,5 с.
- **Цвета:** сукно `#0f3a2d` → почти чёрный `#07100d`; бумага `#f4f1e8`; текст на бумаге `#0f1412`; **золото `#f2c14e` — деньги и главное**; **красный `#ff5a4e` — потери, «нельзя», зачёркивания**; мятный `#3ddc97` — плюс и «правильно»; серо-зелёный `#8ea398` — второстепенное.
- **Шрифты (OFL, в `src/assets/fonts`):** Unbounded — цифры и заголовки; Onest — текст и подписи; JetBrains Mono — таймеры.
- **Движение:** быстрый вход (0,25–0,45 с, «expo out»), долгое удержание, без отскоков и вращений. Выход не анимирован — режьте на нужном кадре или замораживайте последний кадр, если реплика длиннее ролика графики.
- Все цифры в графике сверены со сценарием. Подписи «условный пример» / «иллюстрация» стоят там, где это не реальные данные героя.

## Что лежит в `render/`

- `*.mp4` — полноэкранная графика 1920×1080, 30 fps (фон уже внутри).
- `*.mov` — графика с прозрачностью (QuickTime, кодек PNG) для наложения поверх видео.
- `quotes/<id>-quote.png` — карточки цитат с прозрачным фоном, по одной на каждую реплику Максима и форума (id = номер реплики).
- `no-counter/no-00.png … no-11.png` — состояния счётчика «НО» (прозрачные, правый верхний угол); `no-counter/G28-no-01-center.mov` и `G28-no-10-final.mov` — первый тик и финал в центре.
- `chips/G30-<термин>.png` — сноски-термины (прозрачные).
- Полный список «файл → какие реплики» — `GFX-INDEX.md`.

## Как поправить и перерендерить

Нужны Node 18+, FFmpeg и Playwright с Chromium: один раз в папке `05-GFX/src` выполнить `npm i playwright && npx playwright install chromium`.

```
cd 05-GFX/src
node render.mjs --job ../jobs-scenes.json          # вся графика (пути в файле заданий — от папки 05-GFX)
node render.mjs --job ../jobs-quotes.json          # карточки цитат и счётчик
node render.mjs --job ../jobs-scenes.json --only G17   # только задания, где в имени есть G17
node render.mjs --scene G04-chapter --q "n=05&t=Новое название&d=июнь" --out ../render/G04-chapter-05.mp4
```
Полный рендер всей графики занимает 15–25 минут.

Открыть сцену в браузере для просмотра: `src/index.html?scene=G01-bet&play=1`. Тексты и цифры — в `src/scenes*.js` (каждая сцена — отдельная функция с понятными подписями). Задания на карточки цитат (`jobs-quotes.json`) пересоздаёт `tools/build_package.py` из `tools/script.src.txt`; сами PNG после этого нужно перерендерить: `node render.mjs --job ../jobs-quotes.json`.

## Перерисовка раздачи 6-3 (G29)

Карты в перерисовке по умолчанию закрыты рубашкой: точные карты борда и соперника надо взять с первого скриншота в посте 20 июня (спойлер «минусовые», сразу после подписи про Боссбайдена). Потом:

```
node render.mjs --scene G29-hand --q "hero=6?3?&board=Ah,Kh,7h,2c,9h&vil=Qh,Jd&reveal=0&bettor=hero" --out ../render/G29-hand-placeholder-a.mp4
node render.mjs --scene G29-hand --q "hero=6?3?&board=Ah,Kh,7h,2c,9h&vil=Qh,Jd&reveal=1&bettor=hero" --out ../render/G29-hand-placeholder-b.mp4
```
(борд и карты соперника в примере условные — замените на реальные). Масти: s ♠, h ♥, d ♦, c ♣; `?` — масть неизвестна (у Максима сейчас «6?3?»: по реестру известно только «шестёрка и тройка»). `bettor=hero` — на ривере ставит Максим, соперник отвечает (так в сценарии). Пока карт нет, в `render/` лежат версии `G29-hand-placeholder-a/b.mp4` с закрытыми картами борда и соперника — их можно ставить как есть, если реальные карты не найдутся.

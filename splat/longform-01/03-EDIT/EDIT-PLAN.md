# Монтажный план по репликам

Время — оценка (13 симв/с) для базовой версии; точное даст `tools/timeline.mjs` по реальной озвучке. Обозначения: **Кадр** — что на экране; **Графика** — готовый файл из `05-GFX/render/` (см. `05-GFX/GFX-INDEX.md`); **Движение** — камера/анимация; **Звук** — эффекты из `04-SOUND/sfx/` (см. `04-SOUND/SOUND-PLAN.md`); **Музыка** — смена подложки.

Общие правила кадра — в `03-EDIT/EDIT-RULES.md`. Пост на экране — всегда крупный кроп нужной строки на фоне `G00-bg`, никогда не весь форум мелко.

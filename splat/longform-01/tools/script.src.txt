# === NN | Название главы | дата для плашки | музыка главы

#   key: value — tts / vis / mot / gfx / txt / sfx / mus / pause / win / src / note / no / drop
# ROLE: N — рассказчик; M — Максим (чтение его постов); F:Ник — ответ с форума.

#      добавляется первой, если ролик короче 16:00; res — «＋＋ резерв»: второй эшелон, по умолчанию не озвучивается.

# {NO_ORD} в тексте — подставится порядковое число «но» на этот момент (одиннадцатое и т. п.).

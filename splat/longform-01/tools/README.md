# Инструменты

Нужны: Node.js 18+ (для `.mjs`; ключ из `.env` скрипт читает сам), Python 3.9+ (для пересборки пакета), FFmpeg (`ffmpeg` и `ffprobe` в PATH).
Все команды запускать **из корня пакета** (папка, где лежит `00-START-HERE.md`).

| Команда | Что делает |
|---|---|
| `node tools/tts-batch.mjs` | Сухой прогон озвучки: сколько реплик и символов уйдёт в синтез, первые запросы на экран. Ничего не отправляет (работает и без `voices.json`) |
| `node tools/tts-batch.mjs --go --only 00-01,00-02` | Озвучить конкретные реплики (проба) |
| `node tools/tts-batch.mjs --go` | Озвучить ядро и опции (теги core и cut) в `vo/<id>.mp3`. Готовые файлы не перезаписываются, автоповторов нет |
| `node tools/tts-batch.mjs --go --only 03-07,08-01 --voices 02-VO/voices.candA.json --out vo-test-A` | Проба кандидата в голоса: отдельный файл голосов и отдельная папка (в `vo/` пробы не класть) |
| `node tools/tts-batch.mjs --go --tags res` | Озвучить резерв |
| `node tools/timeline.mjs` | По реальным mp3 собрать `build/vo-spine.wav`, `subtitles.srt`, `timeline.csv`, `chapters.txt`, `markers-resolve.edl`, `report.txt` |
| `node tools/timeline.mjs --drop 02-02,06-15 --add 05-04,07-07` | То же, с точечной подгонкой: убрать две реплики ядра, добавить две опции |
| `node tools/timeline.mjs --tags core,cut` | Ядро + все опции |
| `node tools/timeline.mjs --trim` | Срезать тишину по краям каждого клипа (если в дублях длинные паузы) |
| `python3 tools/build_package.py tools/script.src.txt .` | Пересобрать сценарий, реплики, монтажный план, списки графики после правки `tools/script.src.txt` |

Windows: вместо `python3` — `py -3` (`py -3 tools\build_package.py tools\script.src.txt .`). Файлы можно сохранять с BOM и CRLF — скрипты это понимают. `timeline.csv` и `edit-plan.csv` открываются в русском Excel (разделитель `;`, дробные числа с запятой).

Ключ OpenRouter: файл `.env` в корне пакета (или на уровень выше) со строкой `OPENROUTER_API_KEY=...`. Скрипты ключ не печатают.

## Формат `tools/script.src.txt` (источник правды)

```
=== 05 | Название главы | дата | музыка главы
N | D1 | core | Текст реплики рассказчика.
  tts: текст для синтеза, если отличается (цифры словами, NL → «эн-эл»)
  vis: что в кадре
  gfx: какая графика
  sfx: звук
  pause: 0.4          ← пауза после реплики, секунды
  win: 2.0 — описание ← окно без голоса после реплики
M | M2 | core | Цитата Максима.
  no: +               ← в цитате звучит «но» Максима (счётчик +1)
  drop: 1             ← кандидат на сокращение ядра
F:Ник | F1 | core | Ответ с форума.
```
Теги: `core` — ядро, базовая версия (≈ 16:00 при 13 симв/с); `cut` — «＋ опция»: озвучивается вместе с ядром, но в базовый таймлайн не входит — `timeline.mjs` предлагает её первой, если ролик короче 16:00 (`--add <id>` или `--tags core,cut`); `res` — «＋＋ резерв»: второй эшелон, по умолчанию не озвучивается (`--tags res`). Кандидат на сокращение ядра — не тег, а ключ `drop: 1` (их перечисляет `report.txt`). Не больше двух предложений на реплику — `build_package.py` остановится, если найдёт больше.

После правки `tools/script.src.txt` и пересборки перерендерите карточки цитат (`05-GFX/DESIGN.md`) — PNG сами не обновляются. Если вставили или удалили реплику, id следующих реплик главы сдвинутся: удалите их mp3 в `vo/` и озвучьте заново.
